# Logging and Privacy Notes

## 公开仓库不包含的内容

公开仓库不应包含：

- 真实 API Key；
- 用户上传小说原文；
- 真实运行日志；
- 真实模型响应全文；
- `debug_runs/` 调试目录；
- `backend/logs/` 运行日志目录；
- 本地 `.env` 文件。

## 保留的追踪结构

项目保留以下结构用于解释生成过程：

- `model_trace`：记录模型调用链路；
- `chapter_facts`：记录章节事实抽取结果；
- `repair_questions`：记录修复阶段提出的问题；
- `validation_report`：记录校验问题与最终状态；
- `quality_report`：记录输出质量状态；
- `error_patterns.yaml`：记录通用错误知识库。

这些内容用于本地调试、质量改进和比赛展示，不用于公开保存真实用户隐私文本。

## 推荐比赛表述

本项目提供本地化生成追踪与质量校验机制，可以帮助开发者排查模型调用、章节事实抽取、生成校验和错误修复过程。公开仓库仅保留结构和说明，不包含真实用户文本、真实日志或 API Key。
