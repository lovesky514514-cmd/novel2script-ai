# 03 微信小程序部署包

生成时间：2026-06-07 05:15:27

## 这个文件夹是干什么的

这是 Novel2Script AI 的微信小程序 web-view 演示版，用微信小程序承载线上网页：

```text
https://n2s.cc.cd
```

## 是否涉及版权

本包没有使用第三方图片素材、学校素材、平台素材，也没有复用受版权限制的 UI 资源。  
它只是一个通用小程序 web-view 壳和加载页。

## 使用方法

1. 打开微信开发者工具；
2. 导入 `n2s-wechat-miniprogram/`；
3. AppID 可先使用测试号；
4. 开发阶段可以关闭“校验合法域名”；
5. 编译预览。

## 正式发布提醒

正式发布时，需要在微信公众平台配置业务域名：

```text
https://n2s.cc.cd
```

并保证 HTTPS 证书正常。
