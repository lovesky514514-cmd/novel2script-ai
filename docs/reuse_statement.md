# Reuse Statement

本项目参考本人历史项目中的部分产品设计经验和工程组织思路，但 Novel2Script AI 的前后端结构、小说转剧本流程、YAML 输出结构、错误知识库和生成校验链路均围绕本次题目重新实现。

## 参考经验

- SKY职忆：参考工作台布局、卡片化展示和页面切换思路；
- SKY蓝天：参考记忆精炼和长期上下文管理思路；
- sky_paper_verifier：参考多阶段校验和可解释报告思路；
- career-memory-refinement：参考任务相关上下文压缩思路。

## 本项目重新实现内容

- 小说上传与文本解析；
- 章节事实抽取；
- 分场剧本生成；
- YAML / TXT 导出；
- 继续修改接口；
- 错误知识库 `error_patterns.yaml`；
- `validation_report` / `quality_report`；
- 前后端一键启动流程。
