# 原创与复用说明

## 1. 项目原创性说明

Novel2Script AI 是围绕七牛云 × XEngineer 暑期实训营第三批次题目三重新设计和开发的项目。

项目目标是实现一个 AI 小说转剧本工具，支持将 3 个章节以上的小说文本转换为结构化 YAML 剧本，并通过记忆库、剧作知识库、Schema 校验和质量报告提升输出质量。

本项目不会直接搬运他人项目代码，也不会复制网络公开项目作为主体工程。

## 2. 本项目原创部分

本项目已重新实现以下内容：

1. 小说章节切分流程；
2. 小说事实记忆库；
3. `story_bible` / `chapter_facts` 数据结构；
4. 角色、事件、地点、道具、伏笔、时间线的数据结构；
5. 剧本 YAML Schema；
6. 剧本改编工作流；
7. 分场剧本生成流程；
8. Final Guard 事实绑定流程；
9. YAML 校验与自动修复流程；
10. `validation_report` / `quality_report`；
11. 错误知识库 `error_patterns.yaml`；
12. 前端小说转剧本工作台；
13. 结果卡片、生成进度、YAML 预览和导出界面；
14. 一键启动脚本与项目文档。

## 3. 参考本人历史项目的部分

本项目参考本人历史项目中的部分设计经验，但会围绕本次议题重新实现。

### 3.1 参考 SKY职忆

参考内容：

- 前端工作台布局；
- 蓝白渐变视觉风格；
- 卡片化结果展示；
- 页面切换和轻量动效；
- 结果可读性设计。

用途：

用于提升 Novel2Script AI 的前端可读性和产品完成度。

说明：

本项目没有直接搬运 SKY职忆 作为主体工程。当前实现围绕小说转剧本流程重新开发。

### 3.2 参考 SKY蓝天

参考内容：

- 记忆精炼思路；
- 用户长期上下文管理；
- 历史信息提取和压缩；
- 重要信息保留机制。

用途：

用于设计小说事实记忆库，解决小说长文本改编中的人物遗忘、伏笔丢失和上下文断裂问题。

说明：

本项目将“记忆精炼”思路转换为 `story_bible`、`chapter_facts` 和错误知识库，而不是复用原桌宠项目代码。

### 3.3 参考 sky_paper_verifier

参考内容：

- 多阶段校验流程；
- 置信度报告；
- 证据链展示；
- 输出结果的可解释性设计。

用途：

用于设计剧本质量报告，包括结构合规、人物一致性、事实绑定和人工确认提示。

说明：

本项目重新实现了 `validation_report`、`quality_report` 和 YAML 结构化输出。

### 3.4 参考 career-memory-refinement

参考内容：

- 任务相关上下文压缩；
- 预算约束检索；
- 精炼记忆；
- 减少无关上下文干扰。

用途：

用于优化小说长文本处理时的上下文构建，避免将全文直接塞入模型导致信息混乱或成本过高。

说明：

本项目参考方法思路，实际工程实现围绕小说转剧本任务重新开发。

## 4. 参考公开项目与第三方依赖

本项目使用的主要第三方技术包括：

- React；
- Vite；
- FastAPI；
- Pydantic；
- PyYAML；
- DeepSeek API。

这些依赖仅作为基础开发框架或模型接口使用，不构成对他人完整项目的复制。

## 5. AI 辅助说明

本项目开发过程中使用 AI 辅助进行代码生成、文档整理、错误排查和界面迭代。

最终代码、功能设计、文档内容和比赛提交版本由项目作者整合、测试和确认。

## 6. 隐私与素材说明

本项目不内置未授权小说、影视剧本或课程内容。

演示时建议使用：

- 自写小说样例；
- 已授权文本；
- 公开可改编文本；
- 不包含隐私信息的测试文本。

公开仓库不包含真实用户上传文本、真实运行日志或 API Key。
