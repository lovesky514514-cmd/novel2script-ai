# 原创与复用说明

## 1. 项目原创性说明

Novel2Script AI 是围绕七牛云 × XEngineer 暑期实训营第三批次题目三重新设计和开发的项目。

项目目标是实现一个 AI 小说转剧本工具，支持将 3 个章节以上的小说文本转换为结构化 YAML 剧本，并通过记忆库、剧作知识库、Schema 校验和准确性报告提升输出质量。

本项目不会直接搬运他人项目代码，也不会复制网络公开项目作为主体工程。

## 2. 本项目原创部分

本项目计划原创实现以下内容：

1. 小说章节切分流程；
2. 小说事实记忆库；
3. 角色、事件、地点、伏笔、时间线的数据结构；
4. 剧本 YAML Schema；
5. 剧本改编工作流；
6. 剧本专家 Agent；
7. 剧本医生 Agent；
8. YAML 校验与自动修复流程；
9. 准确性报告生成逻辑；
10. 前端小说转剧本工作台；
11. 结果卡片、步骤流和 YAML 预览界面；
12. Demo 示例与项目文档。

## 5. 不使用的内容

为了避免版权和学术诚信风险，本项目不会使用以下内容：

1. 未授权小说原文作为内置数据；
2. 未授权影视剧本作为知识库；
3. 盗版网文、剧本、课程资料；
4. 直接复制他人项目代码；
5. 直接复制他人 README 或 Demo 文案；
6. 直接套壳本人旧项目作为新作品。

## 6. 知识库版权策略

本项目的剧作知识库将优先使用以下内容：

1. 本人整理的剧作方法论规则；
2. 通用剧作结构说明；
3. 项目自定义的改编规则；
4. 用户主动输入的小说文本；
5. 项目自带的原创示例文本；
6. YAML Schema 文档本身。

不会内置未经授权的小说、剧本或影视作品内容。
